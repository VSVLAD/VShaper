# VShaper (OpenWrt Traffic Shaper)

**VShaper** — легковесный и эффективный инструмент ограничения скорости (шейпер трафика) для локальных клиентов роутера под управлением **OpenWrt** (архитектура `aarch64_cortex-a53`).

Проект разработан на языке **FreeBasic** с использованием объектно-ориентированного подхода и глубоко интегрирован в веб-интерфейс **LuCI**.

---

## 1. Установка пакета

Вы можете установить последнюю версию пакета `luci-app-vshaper` прямо на роутере с помощью `wget` или `curl`, скачав его из релизов GitHub:

```bash
# Обновление списка пакетов
apk update

# Скачивание и установка актуального пакета из релизов GitHub (замените URL на ваш актуальный релиз)
cd /tmp
wget https://github.com/VSVLAD/VShaper/releases/download/v1.0.0/luci-app-vshaper-1.0.0-r1_aarch64_cortex-a53.apk
apk add --allow-untrusted luci-app-vshaper-*.apk
```

## 2. Использование

### Принцип работы
* **Download (Загрузка):** Ограничение входящего трафика для локальных IP-адресов реализуется с помощью стандартного планировщика `tc` (Traffic Control) на выбранном **LAN**-интерфейсе.
* **Upload (Отдача):** Ограничение исходящего трафика реализуется связкой `tc` + классификатора `nftables` на **WAN**-интерфейсе.
* **Атомарность конфигурации:** Модуль управления правилами гарантирует безопасный откат изменений при сбое применения настроек на любом из этапов.

### Управление через веб-интерфейс (LuCI)
1. Перейдите в веб-интерфейс роутера LuCI.
2. Откройте раздел **Службы (Services)** -> **Ограничение скорости**.
3. Вкладка **Общие настройки**:
   * Включите шейпер используя глобальный переключатель `Включить`.
   * Выберите интерфейсы для `LAN` (Download) и `WAN` (Upload). Учитывайте, что интерфейсы не должны совпадать.
4. Вкладка **Правила ограничения устройств**:
   * Добавьте клиентов по IP-адресу (доступен выбор активных клиентов из сети).
   * Установите лимиты скорости для Download и Upload в Кбит/с (допустимые значения от 0 Кбит/с до 10 Гбит/с).
   * Сохраните и примените настройки.

## 3. Сборка проекта

Проект собирается статически под архитектуру ARM64 (aarch64_cortex-a53) из окружения WSL в Windows.

### Структура скриптов сборки и деплоя:
* **`build-bin.sh`** — Компиляция исходного кода на FreeBasic в бинарный исполняемый файл `vshaper`.
* **`build-apk.sh`** — Упаковка скомпилированного бинарника, скриптов инициализации (`/etc/init.d/vshaper`), хуков установки/удаления (`pre-install`, `post-install`, `pre-deinstall`) и LuCI-интерфейса в готовый APK-пакет OpenWrt.
* **`deploy.sh`** — Автоматический деплой собранного APK-пакета на роутер по SSH (считывает настройки подключения, включая `ROUTER_PASS` из локального файла `.env`).
* **`run.sh`** — Вспомогательный скрипт для локального запуска полного цикла сборки и деплоя.

### Задачи в VS Code (`.vscode/tasks.json`)
Для удобной разработки в VS Code настроены следующие основные задачи (доступны через `Ctrl+Shift+P` -> *Tasks: Run Task*):
* **Build Binary:** Компиляция бинарника через `build-bin.sh`.
* **Build APK:** Сборка APK-пакета через `build-apk.sh`.
* **Deploy to Router:** Автоматическая отправка и установка пакета на роутер через `deploy.sh`.
